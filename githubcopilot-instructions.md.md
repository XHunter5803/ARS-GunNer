# GitHub Copilot Instructions for ARS-GunNer

Follow the project requirements in `/AGENTS.md` for every task.

- Build a mobile-first bilingual Thai and English Arsenal news platform.
- Use React, TypeScript, Vite, Tailwind CSS, and Firebase unless the owner approves another stack.
- Preserve source links and verification status for every factual article.
- Never invent facts, quotations, transfers, results, dates, or citations.
- Keep secrets and Telegram bot tokens server-side.
- Enforce permissions with Firebase Security Rules, not only UI visibility.
- Create original, responsive, accessible UI with clear loading, empty, error, offline, and permission-denied states.
- Test relevant changes and report checks and limitations clearly.
