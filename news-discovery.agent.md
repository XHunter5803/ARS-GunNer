# ARS-GunNer Custom Agents

Upload the entire `.github/agents` folder to the root of the `XHunter5803/ARS-GunNer` repository and commit it to the default branch.

The package contains 10 GitHub Copilot custom agent profiles:

1. Lead Architect
2. UI UX Web Designer
3. Frontend Developer
4. Cloudflare Backend
5. News Discovery
6. Fact Checking
7. Article Pattern
8. Language Cleaner
9. Social Publishing
10. QA and Security

After merging the files into `main`, open `https://github.com/copilot/agents`, select the repository, and refresh the agent dropdown.

GitHub Copilot custom agents require an eligible paid Copilot plan. Read `/AGENTS.md` remains the shared project instruction source.
